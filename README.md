# Enterprise Security Audit Lab

## Overview
This project presents a simulated enterprise security audit conducted in a controlled academic lab environment. The assessment reviewed Windows domain controllers, Active Directory, Ubuntu server configuration, IIS web services, authentication controls, patch management, logging, firewall configuration, and access control.

## Objective
The objective of this project was to identify security weaknesses, assign risk ratings, analyze business and technical impact, and recommend practical remediation steps.

## Scope
The assessment covered the following areas:
- Authentication and password security
- Administrator password policies
- Windows LAN Manager and NetBIOS authentication settings
- Active Directory privileged group membership
- File and application permissions
- Sudo access and Linux privilege assignment
- Patch deployment and update frequency
- Logging and monitoring
- Firewall and network traffic controls
- Web server hardening
- TLS/SSL configuration
- Host-based firewall configuration

## Tools and Technologies

## Key Findings
The assessment identified several security weaknesses, including:
- Insecure legacy authentication settings
- Weak password and account lockout policies
- Excessive Domain Admin and Enterprise Admin privileges
- Inconsistent patch management
- Insecure SSH configuration
- Missing host-based firewall controls
- Web traffic not protected by TLS/SSL
- Default IIS content left on the web server
- Unnecessary services increasing attack surface
- Gaps in centralized logging and alerting
